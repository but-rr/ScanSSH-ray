# ScanSSH-ray

Рабочая версия v0.1.4 для Windows 10

### Что реализовано
- Мониторинг выбранного пула
- Статусы SSH, интернета через прокси и доступности ПК.
- Поиск, фильтры, журнал событий в отдельном полупрозрачном окне по кнопке в левой панели.
- При запуске выбран Turbo: только ПК с подтверждённым SSH и интернетом, по возрастанию отклика SSH. Список пересортировывается при обновлении результатов.
- В фильтре «Все» сначала идут ПК с интернетом, остальные проверенные и ещё не проверенные. Внутри групп — по отклику. Отклик измеряет задержку SSH.
- Настройки SSH, прокси, портов и SSH-ключей.
- Выбор ПК и кнопка «Перенаправить трафик».
- Кнопка «Проверить ПК» в карточке устройства: немедленная проверка SSH и интернета выбранного адреса без ожидания интервала проверки прокси. Остальные ПК не проверяются этой кнопкой. Во время текущей проверки повторный запуск недоступен; её можно остановить кнопкой сверху. Автопроверка остальных устройств продолжает работать по своим интервалам.

Кнопка выполняет `.cmd`-файл с SSH-туннелем:

```bash
ssh -L 3128:10.0.0.1:3128 admin@ip (пример)
```

## Стек проекта

- **Go** — логика и мониторинг.
- **Svelte + TypeScript** — интерфейс.
- **Wails v2** — desktop-приложение.
- **Go SSH + OpenSSH** — SSH-подключения.

## Проверка доступности

1. **TCP (порт 22)** — проверка доступности SSH-порта.
2. **SSH** — авторизация с использованием привязанных ключей.
3. **Интернет** — удалённая проверка через корпоративный прокси с авторизацией.
4. **Кэширование** — сохранение результатов и переиспользование SSH-сессий.
5. **Автообновление** — отдельные интервалы проверки SSH и интернета.
