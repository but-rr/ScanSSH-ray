# История изменений

## [0.2.4]

### ⚙️ Улучшения

- Устранён слишком короткий лимит ожидания запуска PowerShell в тестах Windows; добавлена диагностика тайм-аутов.
- Сборка и тесты Windows теперь проверяются при отправке изменений в `main` и создании pull request, до выпуска тега.

## [0.2.3]

### 🐛 Исправления

- Исправлена проверка интернета через прокси при UTF-8 настройках консоли Windows: конфигурация передаётся в curl без лишнего символа BOM.
- Исправлен вызванный этой ошибкой сбой тестов при сборке Windows Release в GitHub Actions.

## [0.2.2]

### 🛠 Новые возможности

- Добавлена автоматическая сборка Windows EXE через Wails и публикация GitHub Release при отправке тега версии.
- Описание релиза берётся только из соответствующего раздела `CHANGELOG.md`.

### ⚙️ Улучшения

- Версия в интерфейсе и свойствах Windows EXE автоматически синхронизируется с тегом перед сборкой.
- Установка зависимостей фронтенда при сборке Wails использует `npm ci` и зафиксированный lockfile.

## [0.2.1]

- Восстановление из трея выполняется в основном потоке окна, без синхронного вызова из обработчика Проводника.
- Уведомления трея разрешены и при запуске приложения от администратора.
- Значок использует постоянный GUID для пути EXE; после аварийного завершения следующий запуск из той же папки удаляет прежнюю регистрацию перед добавлением новой. Запуск из другой папки получает отдельный GUID, как требует Windows для неподписанного EXE.
- Повторный запуск открывает существующее окно вместо создания второго процесса и значка.

## [0.2.0]

- Крестик, Alt+F4 и сворачивание скрывают окно в трей и убирают его с панели задач. Мониторинг и SSH-туннель продолжают работать в фоне.
- Щелчок по значку трея или пункт «Открыть» возвращает окно, сохраняя его размер и развёрнутое состояние.
- Полное завершение — через правую кнопку по значку трея → «Выход». Приложение закрывает туннель и SSH-подключения, останавливает мониторинг и удаляет значок.
- Значок встроен в EXE и восстанавливается после перезапуска Проводника Windows.

## [0.1.7]

- Исправлена высота боковой панели и диалогов на версиях WebView2 без поддержки CSS `dvh`.
- Навигация привязана к видимому окну и уплотняется при небольшой высоте. Заголовок и нижняя панель журнала остаются видимыми, прокручивается только список событий.
- Минимальное окно уменьшено до 760×480. Если при запуске стандартное окно не помещается на мониторе с учётом масштаба Windows, приложение разворачивается в рабочую область экрана.

## [0.1.6]

- Встроенная панель окна вместо стандартного заголовка Windows: сворачивание, разворачивание, восстановление и закрытие.
- Перетаскивание за шапку, разворачивание двойным щелчком и изменение размеров за края окна. Кнопки окна доступны и при открытых настройках или журнале.
- Обновлённая иконка в интерфейсе и EXE. Версия в шапке и свойствах файла — 0.1.6.
